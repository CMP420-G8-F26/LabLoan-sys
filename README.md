# Laboratory Equipment Loan and Return System

## Team Name

**LabTrack Team**

## Project Description

The Laboratory Equipment Loan and Return System is a software system designed to manage the borrowing and returning of laboratory equipment. It allows students and laboratory staff to easily track equipment availability, loan records, due dates, and returned items. The system aims to reduce equipment loss, improve organization, and make the loan process faster and more efficient.

### Main Features

* View available laboratory equipment
* Request and record equipment loans
* Track borrowed equipment and due dates
* Record equipment returns
* Manage equipment and loan records
* Provide users with clear information about equipment status
