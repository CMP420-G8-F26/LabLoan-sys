P1 – Manage Users and Authentication
Input Data: Login credentials, user information, assigned roles
Output Data: Authentication results, user records, access permissions
Rules: Users must provide valid credentials. Only administrators can manage user accounts and roles. Users can only access functions permitted by their roles.

P2 – Manage Equipment
Input Data: Search query, equipment information, item updates
Output Data: Equipment details, availability status, updated equipment records
Rules: Authorized users can search and view equipment. Only authorized staff and administrators can add or update equipment records. Equipment status must be kept up to date.

P3 – Process Loan Request
Input Data: Loan request details, request review, approval/rejection decision
Output Data: Request status, updated loan request
Rules: Students can submit requests for available equipment. Lab staff review requests and approve or reject them. The request status must be updated after a decision.

P4 – Record Checkout and Return
Input Data: Checkout details, expected return date, return details, equipment condition
Output Data: Updated loan status, updated equipment status, return record
Rules: Lab staff record checkout and return details. Each checkout must include an expected return date. Each return must record the actual return date and equipment condition.

P5 – Monitor Overdue Equipment and Send Notifications
Input Data: Active loan records, expected return dates, current date, request decisions
Output Data: Overdue status, reminders, approval/rejection notifications
Rules: Active loans past their expected return date are marked overdue. The system sends appropriate notifications and records relevant activity.
