P1 – Manage Users and Authentication
Input Data: Login credentials, user information, assigned roles
Output Data: Authentication results, user records, access permissions
Rules: Users must provide valid credentials. Only administrators can manage user accounts and roles. Users can only access functions permitted by their roles.

P5 – Monitor Overdue Equipment and Send Notifications
Input Data: Active loan records, expected return dates, current date, request decisions
Output Data: Overdue status, reminders, approval/rejection notifications
Rules: Active loans past their expected return date are marked overdue. The system sends appropriate notifications and records relevant activity.

P6 – Manage Loan History and Generate Reports
Input Data: Loan records, return records, equipment records, report criteria
Output Data: Loan history, return history, equipment usage reports, overdue reports
Rules: Only authorized users may access records. Students can view their own history, while staff and administrators can access reports according to their permissions.
