Use case ID: UC-08
Use case name: Submit loan request
Primary Actors: Student
Purpose: Allow students to request lab equipment for specific dates.
Reason for selection: Shows how the system checks equipment availability, validates dates, and records a pending loan request.

Use case ID: UC-11
Use case name: Approve loan request
Primary Actors: Lab staff / technician
Purpose: Allow lab staff to approve pending requests and reserve equipment.
Reason for selection: Shows how staff review requests, check availability, approve requests, and update their status.

Use case ID: UC-15
Use case name: Record equipment return
Primary Actors: Lab staff / technician
Purpose: Log the physical return of borrowed lab gear, close out the active loan, and update the item's status.
Reason for selection: Models return date, condition inspection, and updated availability.
