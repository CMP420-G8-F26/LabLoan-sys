Exercise 1: Select Three Major Use Cases

Our team selected three use cases from Lab 3. We chose them because they cover the main steps of borrowing and returning lab equipment. We will create one sequence diagram for each use case.

1. UC-08 - Submit Loan Request
Primary actor: Student
Purpose: Allows a student to request lab equipment for certain dates.
Reason for selection: This is one of the main functions of our system. It involves checking if the equipment is available, checking the dates, and submitting a request with Pending status.

2. UC-11 - Approve Loan Request
Primary actor: Lab Staff / Technician
Purpose: Allows lab staff to approve a student's loan request and reserve the equipment.
Reason for selection: It shows how staff review a request, check equipment availability, approve it, and update its status. The system may also send a notification.

3. UC-15 - Record Equipment Return
Primary actor: Lab Staff / Technician
Purpose: Allows lab staff to record when borrowed equipment is returned.
Reason for selection: It shows how the system records the return, checks the equipment condition, and updates the loan and equipment status.

Why We Chose These Use Cases

These three use cases are important parts of our system. They cover submitting a request, approving it, and returning the equipment. They also involve several classes from our Lab 5 class diagram, so they are suitable for sequence diagrams.

We will save the sequence diagrams in the Project/Behavioral_Modeling/Sequence_Diagrams folder in our GitHub repository.
