Rachad Bouida Contributions
1.Authorization: The system shall enforce role-based access control so users cannot access functions outside their assigned permissions.
2.Data integrity: The system shall maintain accurate and consistent relationships between users, equipment, loan requests, loans, and returns.
3.Reliaility: The system shall prevent incomplete or invalid loan and return transactions from being stored as completed transactions.
4.Scalability: The system should be capable of supporting an increase in the number of users and equipment records without requiring a complete redesign.
5.Backup and Recovery: System data shall be backed up regularly so that important user, equipment, loan, and return records can be recovered after data loss.
