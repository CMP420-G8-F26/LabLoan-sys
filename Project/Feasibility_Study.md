# Initial Feasibility Study

## 1. Technical Feasibility

The Laboratory Equipment Loan and Return System is technically feasible because its main features can be developed using normal software development tools available to the team.
The system needs user login, different user roles, equipment records, search and availability, loan requests, checkout and return records, notifications, reports and a database.
The project does not require special hardware because GPS tracking, automated inspection, financial system integration and external inventory integration are out of scope.
Possibly maybe technical challenges could include managing user permissions, keeping equipment status updated, storing loan and return data correctly and implementing notifications.
The project is technically feasible with the available tools and skills.


## 2. Economic Feasibility

The project is economically feasible because it is mainly a software system and does not require expensive hardware or special equipment.
The main resources needed are computers, development software, a database, GitHub and a testing environment. Most of these are already available or free.
There maybe possibly small costs for hosting or email notification services, but no major costs are expected.
The project is economically feasible.


## 3. Operational Feasibility

The system is operationally feasible because it solves problems related to manual equipment tracking.
Manual tracking can cause wrong information, schedule conflicts, lost equipment and difficulty checking if equipment is available or overdue.
Students can search for equipment and submit loan requests, while lab staff can approve requests, record checkout and returns, and monitor overdue or damaged equipment. Administrators can manage users and equipment records.
The system should make the process more organized and reduce the human errors.
The intended users are likely to use and benefit from the system.


## 4. Schedule Feasibility

The project should be possible to complete within the course duration if the we manage the work properly.
The main features include user management, equipment management, loan requests, checkout, returns, notifications, reports and database storage.
We can develop the main features first, such as login, equipment availability, loan requests, checkout and returns, then work on notifications and reports.
The complex features which are GPS tracking, payment processing, external system integration and mobile apps are already out of scope.
The project should be possible to complete within the course schedule.


## 5. Overall Feasibility

And finally based on the technical, economic, operational and schedule feasibility, the Laboratory Equipment Loan and Return System is feasible.
The project can be developed using available tools and resources, does not require major costs, solves a real problem and should be possible to complete within the course duration.
Possible difficulties include limited time, technical problems, integration between system parts, database errors and testing.
We can reduce it by dividing the work properly and focus on the main features first and testing during development.
The project is feasible for development within the course.
